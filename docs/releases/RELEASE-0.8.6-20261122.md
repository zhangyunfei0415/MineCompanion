# MineCompanion 0.8.6

构建 `release-0.8.6-20261122-02`，正式发布版。适用于 **Minecraft Java 1.20.1 · Forge 47.4.x · Java 17**。安装包内的运行文件为 `logistics-companion-0.8.6.jar`（`16,252,660 B`，SHA-256 `0560FAA992C7465D24D53C4F1F52D2609834F660F25A358F93327ED01FBF0572`）。

## 本版分工

- **项目维护者**负责产品规划、实机连测问题定位（双开公屏自回、驻守拾取与 `[BUSY]` 阻塞、刷石机连挖与内置连点器需求）、拟定 `0.8.6 → 0.8.7rc* → 0.8.7` 版本节奏，并提供「Gemini 星灵」双画风立绘。
- **Gemini**完成 `0.8.6rc1`–`0.8.6rc4` 与 `0.8.6` 收口演进、7 项最终审阅加固、自动化测试扩充与本版正式打包发布。
- **OpenAI Codex**完成 `0.8.6` 首轮三维探索记忆与安全回程图底座，以及前序版本发行基线。
- **DeepSeek Harness（DSH）**参与多轮科技模组 GUI、热力储能 NBT 同步、后室探索与伴随陪伴实机测试与问题反馈。

各阶段完整记录与历史署名见 [版本与贡献记录](../../VERSION-HISTORY.md)。

## 0.8.6 核心更新（对比 `0.8.5rc1`）

1. **三维探索记忆与「空间与地图」系统（`rc1` / `rc2`）**：按世界与维度持久记录探索拓扑、岔口与安全地标，提供 `explore_*` 工具与可缩放分层探索地图；工作台与辅助窗统一更换适配 6 套明暗主题的 `DeskEditBox`。
2. **通用科技模组 GUI 同步与 G9/G10 修复（`rc2` / `rc3`）**：支持标准服务端容器包的通用重同步与失败槽位诊断；`VolatileTagPolicy` / `StackSyncMatcher` 剥离热力/机械动力/植物魔法等易变 NBT 标签，新增生存可用 `resync_inventory`。
3. **女仆式「跟随与陪同」值守、自主切档与共享注意力（`rc3` / `0.8.6`）**：支持 `纯待命` / `驻守基地` / `跟随与守护` / `外出探索采集` 四档值守与三档自主权（`AI全权自主调档` / `仅安全自主调档` / `人工锁定模式`）；驻守模式持续清场拾取（跳过滞留掉落与 45 秒卡死冷却）；双开同目录零公屏串台 + 只读联动伴侣状态与 3D 地图；新增 `observe_owner_focus` 与 `handoff_to_owner` 安全递物资；前台派单与工作台手动指令零 `[BUSY]` 抢占。
4. **移动、涉水、爬梯、跑酷、过门与 F4 节能（`rc4` / `0.8.6`）**：支持 1 格浅水涉水、梯子/藤蔓垂直攀爬、可控助跑跑酷、`NavigationPassage` 木活板门（带防坠坑保护）与按钮/拉杆铁门通行；新增 **F4** 一键限帧静音节能模式。
5. **刷石机安全放行、内置挂机引擎与「Gemini 星灵」双画风立绘（`0.8.6`）**：`GeneratorPolicy` 放行干地安全水平流体槽刷石/玄武岩定点挖掘（兼容底部水收集道）；新增 `auto_action` 与工作台一键挂机（刷石机连挖换镐、刷怪塔满蓄力清怪、手摇曲柄长按自动进食、筛网/骨粉连点自动补料）；新增「**Gemini 星灵**」高清与 MC 像素 4×2 透明立绘，实时响应 8 种伙伴工作姿态。

## 安装与验证说明

1. 下载 **`MineCompanion-0.8.6.zip`**，关闭游戏后将 `logistics-companion-0.8.6.jar` 放入对应 Forge 1.20.1 客户端的 `mods/` 目录（更新前请备份旧 JAR 与配置）。
2. 本版已通过离线洁净构建及 **136 个 JUnit 测试套件 / 705 项自动化测试**（0 失败 / 0 跳过），`coremods/companion_input.js` 保持未改。
3. 本版刚合入 `0.8.6` 收口特性与最终审阅修补，欢迎在实机双开、刷石机、机械动力挂机与女仆值守场景中继续验证反馈。
